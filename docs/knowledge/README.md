# Knowledge

Purpose:

Curated reference knowledge and learnings that inform documentation and implementation decisions — distinct from the platform's own `05-Knowledge/` engine (which is a runtime component storing QA standards, automation patterns, and business rules for the AI Agents themselves). This folder is for the humans and Claude Code sessions writing the docs, not for the running platform.

Naming convention:

Descriptive, no number required — this is a reference library, not a sequential build log.

Example (once authored):

```
Requirement-Analysis-Patterns.md
Common-Locator-Strategies.md
```
