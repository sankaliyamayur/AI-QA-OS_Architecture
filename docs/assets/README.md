# Assets

Purpose:

Images, exported diagrams, and other binary files referenced from Markdown docs elsewhere in `docs/` — anything that can't be expressed as a Mermaid block per `../../AI-QA-OS-Documentation-Standard.md` Section 4.

Naming convention:

Descriptive, grouped by the folder that references them where practical.

Example (once authored):

```
architecture/system-diagram-v1.png
verification/01-execution-screenshot.png
```

Status:

No files yet. Reference assets with relative Markdown image links, e.g. `![System Diagram](../assets/architecture/system-diagram-v1.png)`.
