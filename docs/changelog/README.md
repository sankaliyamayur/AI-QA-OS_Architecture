# Changelog

Purpose:

Per-component technical changelog — one file per platform component (mirroring the `01-Core/` and `03-Agents/` module names from the Repository Construction Blueprint), tracking what changed inside that component across Steps. Distinct from `roadmap/Version-History.md` (changelog of the documentation set itself) and `release-notes/` (user-facing, per shipped version).

Naming convention:

```
Component-Name.md
```

Example (once authored):

```
qa-brain.md
workflow-engine.md
requirement-agent.md
```

Format: same `## [Version] - YYYY-MM-DD` structure defined in `../../AI-QA-OS-Documentation-Standard.md` Section 9.

Status:

No files yet. Create a component's changelog file the first time that component is implemented.
