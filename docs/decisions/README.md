# Decisions

Purpose:

Architecture Decision Records (ADRs) — a short record for each significant, hard-to-reverse decision (why Claude over another model, why a given automation framework, why a given repository layout), so the reasoning survives even after the decision itself is old news.

Naming convention:

```
NNN-Descriptive-Title.md
```

Example (once authored):

```
001-Use-Claude-As-Primary-Model.md
002-Adopt-Numbered-Docs-Naming-Convention.md
```

Each ADR should record: Status (Proposed/Accepted/Superseded), Context, Decision, Consequences.
