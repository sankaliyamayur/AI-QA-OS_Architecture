# Release Notes

Purpose:

User-facing summary of what shipped in each released version — what's new, what changed, upgrade notes. Distinct from `changelog/`, which is per-component and technical, and from `roadmap/01-Release-Plan.md`, which is forward-looking (what's planned, not yet shipped).

Naming convention:

```
vX.Y.Z.md
```

Example (once authored):

```
v1.0.0.md
```

Status:

No files yet. The first file is created when `roadmap/01-Release-Plan.md`'s 1.0.0 checklist is complete and the release is actually cut.
